```
# Actividad 1 - Repositorio de Ejercicios de Programación Web
Este repositorio contiene los ejercicios completos a la serie de prácticas de la
**Actividad 1**, enfocadas en los fundamentos de estructura HTML, estilización
con CSS y lógica interactiva mediante JavaScript.
```

# `Descripción de la Actividad` 

```
El objetivo principal es aprender y consolidar la estructura de contenido básico
utilizando etiquetas fundamentales de HTML5, organización mediante secciones
semánticas, creación de formularios accesibles, manipulación de estilos CSS y
desarrollo de funciones interactivas en JavaScript sin dependencia de librerías
externas.
```
